# Лапка — приют для животных

Лапка — frontend-сайт приюта для животных. Проект предназначен для знакомства с животными, которые ищут дом, получения информации о приюте и выбора подходящего способа помощи.

## Возможности

- каталог животных с фотографиями, именами, возрастом и описанием;
- фильтрация животных по категориям: все, собаки и кошки;
- всплывающие окна с подробной информацией о животных;
- форма помощи с выбором способа участия;
- варианты помощи: стать хозяином, стать волонтёром или помочь финансово;
- автоматический выбор животного при переходе к форме помощи;
- валидация имени, фамилии и электронной почты;
- проверка обязательных полей формы;
- FAQ с раскрывающимися ответами;
- история приюта в формате timeline;
- анимации элементов при прокрутке;
- адаптивная версия сайта для мобильных устройств;
- контактная информация и ссылки на социальные сети.

## Стек

- Frontend: HTML5, CSS3, JavaScript;
- Styling: CSS Grid, Flexbox, Media Queries;
- Browser API: DOM API, Intersection Observer API.
